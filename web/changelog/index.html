Changelog

Every release of the extension, newest first. The full development history is public in the open-source repository.

0.1.6 August 4, 2026

  • Shorter name. The extension is now called simply "Color Picker from Image" in every language — no subtitle after it.

0.1.5 August 4, 2026

  • Rate us. The popup links straight to the extension's Chrome Web Store reviews page.

0.1.4 August 1, 2026

  • Fixed: "Grab this page" and right-click picking could open a blank second picker tab while the grabbed image landed in an old one. The picker tab is now reused reliably.

0.1.3 August 1, 2026

  • Fixed: on high-resolution displays "Grab this page" could fail because the screenshot was too big to hand over to the picker. Oversized screenshots are now scaled down automatically.
  • Capture errors show what actually went wrong instead of a generic message.

0.1.2 August 1, 2026

  • Clearer message on protected pages: grabbing works on regular websites whose address starts with http or https.

0.1.1 August 1, 2026

  • "Grab this page" from the picker. The hint in the picker header opens the extension popup with the real Grab button highlighted.
  • Website, Rate us and GitHub links in the popup.
  • Esc clears the crosshair; any arrow key brings it back centered.

0.1.0 August 1, 2026

  • First release. Open, drop or paste (Ctrl+V) an image and pick any pixel from it.
  • Zoom loupe with a pixel grid; arrow keys move 1 px (Ctrl — 10 px), Enter picks.
  • HEX, RGB and HSL with one-click copy, plus optional auto-copy of HEX.
  • Automatic 8-color palette of the image.
  • History of your last 50 colors, kept between sessions.
  • Right-click any picture on a page — "Pick color from this image".
  • "Grab this page" captures the visible tab as an image.
  • Light and dark themes, 52 languages, works fully offline — no host permissions, no accounts, no tracking.
