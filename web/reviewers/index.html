Как оставить отзыв

  1. Поставь расширение: Chrome Web Store
  2. Открой пикер (иконка на панели → Open picker) и брось туда любой скриншот или лого — или просто нажми Ctrl+V
  3. Ниже есть список вопросов для вдохновения для отзыва
  4. Вернись на страницу расширения в сторе: вкладка Reviews → Write a review, напиши своими словами и отправь
  5. Для взаимного отзыва напиши в тг @minisol — и сюда же, если нашёл баг :)
